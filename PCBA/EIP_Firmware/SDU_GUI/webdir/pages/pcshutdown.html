PC Shutdown ⓘ This will enable all of the PC Shutdown features and act based on battery health parameters and power status.

PC Shutdown Configuration
 Keep PC ON as long as possible ⓘ This mode keeps PC ON until battery too low threshold point or battery cutoff point is reached.
 Preserve Battery Power ⓘ This mode allows user to set Shutdown delay. After power goes off the PC will be ON until shutdown delay elapses and then shutdown will be triggered.

mm ss Max: 2 Hours
 Shutdown Delay Counter ⓘ The PC Shutdown Delay Counter enable/disable feature allows the user to activate a countdown display on screen when 15 seconds remain before shutdown.
 PC Re-Start Delay ⓘ This allows the user to restart the PC once main power returns. After power is restored, the UPS output remains OFF for a configured delay period beforev turning ON to start the PC smoothly. (To enable this operation, the BIOS setting → PC boot option must be set to 'Wake up on power.')
